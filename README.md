# GitHub User Finder

**Автор:** Корыстылёва Анна Сергеевна
**Дата:** 04.05.2026

## Описание

GitHub User Finder — это десктопное приложение с графическим интерфейсом, которое позволяет искать пользователей GitHub по имени пользователя, просматривать их основную информацию и сохранять избранных пользователей локально в JSON-файл.

## Как использовать GitHub API

Приложение использует публичный REST API GitHub v3:

- **Endpoint:** `https://api.github.com/users/{username}`
- **Метод:** GET
- **Ответ:** JSON с информацией о пользователе: `login`, `avatar_url`, `html_url`, `type` и др.

Аутентификация не требуется для обычного поиска публичных пользователей (ограничение: 60 запросов в час для неавторизованных запросов).
